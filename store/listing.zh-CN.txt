名称
TranslateMyPage：AI 沉浸式双语翻译

简短介绍
AI 网页翻译，原文译文对照、保留排版，支持划词翻译。翻译可使用自己已授权的 ChatGPT 订阅额度。需安装 macOS / Linux 本地助手。

详细介绍
AI 网页翻译，让你在原网页持续阅读。

TranslateMyPage 是一款 AI 网页翻译工具，支持沉浸式双语阅读、划词翻译与网页排版保留。原文留在原位，译文贴近上下文；翻译请求可使用你通过官方流程授权的 ChatGPT 订阅额度。

【共用自己的 ChatGPT 订阅额度】
在官方页面登录并授权，扩展根据当前账号读取可用模型。无需另外填写 OpenAI API 密钥。模型调用会计入你授权的 ChatGPT 套餐；实际可用模型、额度和资格以账号、工作区及 OpenAI 当时的设置为准。

【沉浸式双语阅读】
按段落展示原文与译文，保留对应文本的字体、字号、颜色、行距，以及链接、加粗、斜体和行内代码等格式。支持标题、段落、列表和表格，在阅读动态网页时增量处理新内容，也可一键恢复原文。

【划词即译】
激活当前页面后，选中正文并松开鼠标，翻译小球会跑到选区旁等待，完成后展开游戏风格对话框。也可使用 Alt+T。支持关闭、Escape 和手动重试。

【会表达状态的小球】
闭眼睡觉表示未开启翻译，睁眼和闪烁的灯光表示正在翻译，灯泡常亮表示已就绪。小球可以自由拖动，并记住停靠位置；唤醒、跑动、返回和对话框开合都有过渡动画，支持系统的“减少动态效果”。

【本地助手与隐私】
首次翻译前会说明将待译文字、页面标题和命中的术语发送给 OpenAI，并征得你的同意。授权凭据保存在操作系统凭据库中，译文缓存在本机。扩展仅在你操作后取得当前页的临时访问权限；代码块、表单、密码框和可编辑输入区默认排除，不支持无痕窗口。

使用前请注意
• 需要另外安装配套的 Native Messaging 本地助手；只安装 Chrome 扩展不能完成翻译。
• 当前助手支持 macOS，以及具备 Secret Service 的 Linux。Windows 和 ChromeOS 当前不支持。
• 当前安装方式需要 Node.js 22.16 或更新版本；macOS 需要 Xcode Command Line Tools，Linux 需要 secret-tool 与桌面 Secret Service。
• 使用符合条件且已授权套餐调用的 ChatGPT 账号。翻译会使用该账号的套餐额度。
• 普通 HTTP/HTTPS 网页为首版支持范围；复杂 Shadow DOM、跨域 iframe、PDF、字幕和 OCR 暂不支持。
• 界面当前主要为简体中文。AI 翻译可能出现错误，可随时与原文对照。

TranslateMyPage 是独立开发的翻译工具。ChatGPT 和 OpenAI 为其各自权利人的商标；本产品并非 OpenAI 或“沉浸式翻译 / Immersive Translate”的官方产品，也与其无隶属关系。
