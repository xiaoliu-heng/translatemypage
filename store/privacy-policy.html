TranslateMyPage 隐私政策

生效日期：2026 年 11 月 3 日。适用版本：0.2.1 起的 Chrome / Microsoft Edge 扩展。

TranslateMyPage 是由 xiaoliu-heng 维护的免费开源 AI 网页翻译扩展。支持及隐私联系邮箱：xiaoliublog@gmail.com。

数据处理与用途

数据用途和去向
主动翻译的正文、选中文字、页面标题、命中的术语、语言设置说明并征得当前提供商来源的同意后，直接发给所选 OpenAI 或自定义 Responses 兼容服务商，生成译文。HTTPS 地址加密传输；用户自选 HTTP 地址时以明文传输。格式还原不发送链接地址、CSS 或可执行代码。
当前网页的地址、站点名称、页面生命周期仅本机用于站点规则和结果归属；不调用浏览历史 API，不建立历史档案，不将完整地址加入模型提示。
登录返回的姓名、邮箱、主体、账号状态在本次扩展会话内存中用于账号识别、选择和显示，不持久保存姓名、邮箱或原始主体。
用户粘贴的回调地址、一次性授权码、state、nonce、PKCE verifier在会话页内存中校验本次登录并向 OpenAI 兑换令牌；输入提交后立即清空，不通过网页消息路由或日志转发完整链接。
OAuth 访问、刷新和身份令牌只保留在扩展会话标签页的内存中，用于 OpenAI 模型调用、刷新及退出撤销。不写入 chrome.storage、localStorage、sessionStorage、IndexedDB、同步存储、日志或分析服务。
用户配置的 API key 与服务商地址原始密钥、规范化基础地址、连接摘要与最近明确选中的 API 连接保存在扩展自己的 IndexedDB，未加密、不使用同步存储，关页、刷新或重启后仍保留。模型目录与翻译通过 Bearer 请求头直接发送到该连接的地址；HTTP 地址不加密。提交或取消后清空输入，密钥不经过后台或网页消息路由，不写入 chrome.storage.local、日志或分析服务。
随机 Host 标识、已签发客户端 ID、账号绑定摘要保存在 chrome.storage.local，避免重复注册和账号混用。Host 标识会发送给 OpenAI；它不是邮箱、硬件指纹或令牌。
译文、缓存摘要键、最近使用时间保存在扩展自己的 IndexedDB 中，按账号隔离，最多 2,000 条，按最近使用淘汰。
语言、模型、术语、排除规则、内容发送确认、logo 位置、API 连接摘要保存在 chrome.storage.local，不使用浏览器同步存储。API 连接摘要由基础地址和密钥作单向 SHA-256 摘要，用于隔离模型设置和译文缓存，不是原始密钥。

共享与服务提供方

OpenAI 提供 ChatGPT 身份授权、签名校验与套餐推理。API key 模式直接连接用户配置的 OpenAI 或自定义 Responses 兼容服务商；保存或刷新模型目录时即向该服务商发送密钥，翻译内容另需发送确认。请求不经过开发者托管的中转服务器。没有广告、分析或第三方追踪 SDK，不出售数据，不向数据经纪商提供数据，不读取 ChatGPT 历史对话。

模型请求设置 `store: false`，不代表任何提供商承诺不处理或保留数据。用户应自行了解所选服务商的条款、数据保留和账号控制。

权限、同意与触发

普通 HTTP/HTTPS 主文档默认加载打包的内容脚本显示 logo，因此需要普通网页的全站内容脚本访问权限；未开启时不扫描正文或发起翻译。`activeTab`、`scripting` 支持工具栏当前页操作；`storage` 用于本机偏好与注册信息。固定网络权限为 `auth.openai.com` 和 `api.openai.com`，自定义 API 保存或手动刷新时按主机申请可选权限。Chrome 主机权限不区分端口。不使用 Native Messaging、本地助手或浏览历史 API。

点击 logo 开启或关闭翻译。首次向当前提供商来源发送内容前披露并征得同意，来源包含协议、主机、端口，更换来源需重新确认。开启后的增量翻译持续至停止、离开或关闭页面。语言识别在本机逐段进行，与目标一致时跳过；不确定时保守翻译，同原文的返回结果不重复显示。表单、密码框、可编辑区和代码块默认排除。正文仍可能含个人信息，请确认适合发送；无痕窗口不支持。

会话与本地保留

运行中的翻译需要“翻译会话”标签页。关闭、刷新、重启或更新会丢弃 OAuth 内存凭据，ChatGPT 需重新授权；API key 与基础地址保留，可按需恢复最近明确选中的 API 连接。选择 ChatGPT 后不会自动回退到已保存 API 连接。扩展禁止自动丢弃会话页，不自动重放断开时结果未知的请求。直接关页不保证远端授权被撤销。

ChatGPT 连接退出时，会先停止该账号的新请求，尝试撤销最新刷新令牌，然后清除内存凭据。如果未确认远端撤销，会明确提示在 ChatGPT 设置中断开应用。客户端 ID 和绑定摘要保留，以便下次重新授权。身份验证成功不等同于套餐推理权限已获授予。

API 模式的“删除已保存的密钥”停止该连接并删除其本地持久记录，不撤销服务商平台的密钥；关闭会话页不删除记录。撤销请到相应服务商平台操作。ChatGPT 与 API 不自动互相回退，API 调用按所选平台用量单独计费。

密钥、偏好、注册信息和未淘汰缓存保留至用户删除或卸载。API key 与译文缓存都不是加密保险库，受浏览器配置和操作系统权限保护；能访问浏览器配置目录的人或软件可能读取密钥。开发者不能远程读取或删除本机数据。使用 HTTP 服务会以明文传输密钥和内容，只应在可信环境使用。

用户控制与删除

  • 停止翻译、恢复原文或关闭划词对话框。
  • 在扩展设置清空译文缓存，修改或删除术语和排除规则。
  • 在扩展中退出 ChatGPT，关闭会话以丢弃 OAuth 内存凭据，或使用“删除已保存的密钥”删除 API 连接。
  • 在 ChatGPT 设置或相应 API 服务商平台查看用量、管理和撤销远端权限 / 密钥；删除本地密钥或卸载不等于远端撤销。
  • 移除扩展或通过浏览器扩展数据管理清除本机 API 密钥、偏好、注册信息和缓存；清空译文缓存不会删除 API key。
  • 旧版 0.1.x 的助手资料与系统凭据不会被此版读取、迁移或自动删除。旧资料位于 macOS 的 `~/Library/Application Support/TranslateMyPage/`，或 Linux 的 `${XDG_DATA_HOME:-~/.local/share}/translatemypage/`；旧系统凭据使用 `com.translatemypage.` 前缀。请在退出旧账号并停止旧助手后另行清理。
