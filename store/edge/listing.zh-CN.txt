TranslateMyPage：AI 沉浸式双语翻译

简短介绍
AI 网页与划词翻译，原文译文对照、保留排版。支持 ChatGPT 授权或 OpenAI API key（API 单独计费），无需助手。

详细介绍
TranslateMyPage 帮助你翻译网页和选中文字，保留原文对照与网页格式。免费开源，采用 MIT 许可证。

【沉浸式 AI 翻译】
原文与译文在同一页对照，保留字体、字号、颜色、行距、链接、加粗、斜体、行内代码和换行。支持标题、正文、列表与表格，可随时恢复原文。

【划词翻译与可拖动小球】
选中文字后，小球移动到选区旁显示呼吸灯，翻译完成后展开游戏风格对话框。闭眼睡觉表示关闭，灯泡常亮表示就绪。拖动保存位置，支持快捷键、手动重试与减少动态效果。

【ChatGPT 订阅或 OpenAI API key】
在 OpenAI 官方网页授权后，可使用账号实际可用的模型与 ChatGPT 订阅额度，无需另填 API 密钥。也可在会话页设置个人 OpenAI API key，通过 Responses API 翻译；此方式无需回调登录，必须主动选择兼容的文本模型，按 API 用量单独计费。两种方式不会自动互相回退。

【安装与登录】
仅安装桌面浏览器扩展，无需本地助手或 Node.js。首次在扩展中打开翻译会话页，进入官方授权页。授权后跳转至 127.0.0.1/auth/callback（含端口）时，浏览器可能显示无法连接；复制地址栏完整链接，粘贴回扩展会话页完成验证。
请保持翻译会话标签页打开；关闭、刷新或重启浏览器后需重新授权或重新输入 API key。令牌与密钥只在会话页内存中，不写浏览器存储。断开 API key 只清除本地凭据，不撤销平台密钥。手动回调是本项目的 ChatGPT 登录适配方案。

【隐私】
首次翻译前说明内容发送。请求直接发给 OpenAI，没有开发者中转服务、广告或分析 SDK。译文按账号缓存在本机，可清除。无痕窗口、PDF、跨域 iframe 和复杂 Shadow DOM 暂不支持。

AI 翻译可能有误，请结合原文判断。
