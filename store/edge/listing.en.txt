Name
TranslateMyPage: AI Bilingual Translation

Short description
AI webpage and selected-text translation with formatting. Uses your authorized ChatGPT plan quota. Requires a macOS/Linux helper.

Detailed description
AI webpage translation for immersive bilingual reading.

TranslateMyPage is a free, open-source Microsoft Edge extension for webpages and selected text. Read original paragraphs and their translations together while retaining page formatting. Translation requests can use your own ChatGPT plan quota through official authorization.

Installation requirements: a separately installed local helper is required. This release supports macOS and Linux with a desktop Secret Service. Windows, ChromeOS and mobile browsers are not supported. The helper requires Node.js 22.16+; macOS also needs Xcode Command Line Tools, and Linux needs secret-tool and xdg-open.

Read in two languages
Display translations next to the original paragraphs. Preserve typography, links, emphasis and inline code. Supports headings, paragraphs, lists, tables, incremental dynamic content and restoring the original page.

Translate selected text
After activating the current page, select reading text and release the pointer. A draggable companion approaches the selection, waits with a pulsing light and opens a game-style dialogue when the result is ready. Alt+T, Escape, close and manual retry are supported.

A reading companion
Closed eyes indicate translation is off, a pulsing light indicates work in progress and a steady light indicates readiness. Drag the companion to a preferred position. Wake, travel and dialogue animations respect reduced-motion preferences.

Use your own ChatGPT plan quota
Sign in on the official authorization page and choose from models actually available to your account. No separate OpenAI API key is required. Requests count toward your authorized ChatGPT plan's usage. Model availability, eligibility and limits depend on your account, workspace and OpenAI settings. TranslateMyPage is free under the MIT license and adds no subscription fee.

Local helper and privacy
The helper handles account connection, operating-system credential storage and translation requests; the extension handles webpage content and translation display. Edge starts the helper as needed. AI inference runs at OpenAI. Credentials remain in macOS Keychain / Linux Secret Service, and translations are cached locally. Requests go directly to OpenAI, without a developer-operated inference proxy, advertising or analytics SDK.

Before the first translation, the app asks for consent to send text, the page title and matching glossary terms to OpenAI. Current-page access follows your action. Forms, passwords, editable fields and code blocks are excluded by default. Incognito is not supported.

Before installing
• The Edge extension alone cannot translate. Download and install the helper using the setup instructions.
• Requires an eligible ChatGPT account with plan usage authorized.
• Standard HTTP/HTTPS main-document content is supported. Complex Shadow DOM, cross-origin iframes, PDF, EPUB, subtitles and OCR are outside this release's scope.
• The interface is primarily Simplified Chinese. AI translations can be inaccurate; keep the original for comparison.
