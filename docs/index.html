AI 网页翻译
沉浸式双语阅读。

AI 翻译网页和选中文字，原文译文对照，保留排版，划词即译。翻译请求可使用自己已授权的 ChatGPT 订阅额度。

下载本地助手与源码GitHub 项目隐私政策

Chrome 商店尚未提交审核。完整源码包和助手已在 Releases 公开；发布状态以项目说明为准。扩展需要配套本地助手，当前支持 macOS / Linux。Windows 和 ChromeOS 暂不支持。

翻译能力优先，阅读持续流畅

  • 官方 Sign in with ChatGPT 授权；使用账号实际可用的模型，无需另填 API 密钥。
  • 双语段落、列表与表格；保留字体、颜色、链接、强调和行内代码。
  • 选中文字，小球跑到选区旁等待；完成后展开游戏风格对话框。
  • 拖动小球改变停靠位置；呼吸灯、唤醒、入睡和对话框动画支持减少动态效果。
  • 凭据留在系统钥匙串 / Secret Service，译文缓存在本机；翻译请求直接发给 OpenAI。

安装配套助手

需要 Node.js 22.16+。macOS 另需 Xcode Command Line Tools；Linux 另需 secret-tool、桌面 Secret Service 与 xdg-open。从 Releases 下载并解压 helper ZIP，在解压目录运行：

node scripts/install-host.mjs --extension-id=商店条目的32位扩展ID

该 ID 位于商店网址末尾，也可从扩展详情页复制。商店正式发布前，可使用仓库 README 中的开发版安装方式。

首次使用时，在扩展中点击 Continue with ChatGPT，完成官方登录和套餐使用授权，再确认网页内容发送说明。调用会使用你的 ChatGPT 套餐额度；可用模型、账号资格与额度以 OpenAI 及工作区设置为准。界面当前主要为简体中文。
