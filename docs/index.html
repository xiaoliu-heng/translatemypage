沉浸式双语阅读。

翻译网页和选中文字，保留原文对照、字体、链接与格式。可使用自己已授权的 ChatGPT 订阅额度。

源码与安装说明隐私政策

0.2.0 是正在验证的免助手开发版，尚未上架商店。已实现手动回调登录，实际扩展中的授权兑换和翻译仍待验证；旧版 Releases 采用不同架构。

只需安装扩展

  1. 加载构建好的扩展，打开翻译会话标签页。
  2. 进入 OpenAI 官方授权页，登录并授权。
  3. 跳转到本机回调地址后，复制地址栏完整链接，粘贴回扩展完成验证。此时显示无法连接属于预期现象，无需本地服务。
  4. 保留会话页，切回网页，从工具栏扩展按钮开启翻译。

登录令牌仅在会话页内存中。关闭、刷新或重启浏览器后需要重新授权。手动回调是本项目对官方流程的适配。

为阅读保留上下文

  • 双语段落、列表与表格，沿用原文格式，可恢复原文。
  • 选中文字，小球移动到选区旁等待，完成后展开游戏风格对话框。
  • 浮球支持拖动、位置记忆和减少动态效果。
  • 请求直接发往 OpenAI，译文缓存在本机，可随时清除。

模型、账号资格和额度由 OpenAI 及工作区设置决定。AI 翻译可能有误，请结合原文判断。
