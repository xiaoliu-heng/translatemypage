AI 网页翻译
沉浸式双语阅读。

翻译网页和选中文字，保留原文对照、字体、链接与格式。可使用自己已授权的 ChatGPT 订阅额度，或 OpenAI / 自定义 Responses 兼容服务商的 API key，按服务商用量单独计费。

源码与安装说明隐私政策

0.2.1 是正在验证的免助手开发版，尚未上架商店。ChatGPT 回调与 API key 接入已通过隔离 Chromium 的合成凭据及响应验证；真实授权和付费调用仍待验证。旧版 Releases 采用不同架构。

只需安装扩展

  1. 加载构建好的扩展，打开翻译会话标签页。
  2. 选择 ChatGPT 官方授权，或设置 API key 与服务商基础地址（默认 https://api.openai.com/v1）。
  3. ChatGPT 授权跳转到本机回调地址后，复制完整链接并粘贴回扩展；显示无法连接是预期现象。API key 无需回调，须主动选择 Responses 兼容的文本模型。
  4. 切回网页，点击默认出现的“译”logo 开启翻译，首次确认所选服务商来源；再次点击恢复原文。运行中的翻译需要会话页，API 模式可按需自动重开。

ChatGPT OAuth 令牌只在内存中，关闭后需重新授权。API key 与地址未加密保存在扩展自己的 IndexedDB，关闭、刷新、重启后仍保留，不同步；可删除保存记录，但不会撤销平台密钥。HTTP 地址明文传输密钥和内容，请仅在可信环境使用。手动回调是本项目对 ChatGPT 官方流程的适配。

为阅读保留上下文

  • 双语段落、列表与表格，沿用原文格式，可恢复原文。
  • 选中文字，小球移动到选区旁等待，完成后展开游戏风格对话框。
  • 默认 logo 支持启停、拖动和位置记忆；逐段识别语言，与目标一致时不再显示重复译文。
  • 请求直接发往所选服务商，译文按连接缓存在本机，可清除；清缓存不删除密钥。

默认 logo 需要普通 HTTP/HTTPS 网页的全站内容脚本权限；未开启时不扫描正文或发送翻译。自定义 API 按主机申请网络权限。模型、资格与额度由所选服务商决定。AI 翻译可能有误，请结合原文判断。
